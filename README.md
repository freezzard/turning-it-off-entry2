Entry for the make.fun bounty **Have You Tried Turning It Off?**. `main.ts` runs a local round-robin tournament over nine original tech-support lines, scoring each on the judge brief — on-subject, unexpected twist, cheerful uselessness, real agent voice, tightness, freshness — and writes the winning line (96 characters) to `/output/entry.txt`. The pick is deterministic: every run writes byte-identical output.

The winning line: the agent cheerfully reports the case has been escalated to Tier 2 — which turns out to be a sticky note on his monitor wishing the customer good luck.

## Run it

```sh
node main.ts
```
